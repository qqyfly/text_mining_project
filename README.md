# Email spam classification with GPT2 and BERT

This repository contains the code for the paper "Email spam classification with GPT and BERT".
And this repository is for the final project of the course "Text Mining" at the University of Linköping.

## Folder structure
- `code/`: Contains the ipython notebooks/ipynb pdf for the experiments.

## Reminder
- The code is tested on Google Colab with GPU enabled.
- The data used in this project is download from [Kaggle](https://www.kaggle.com/api/v1/datasets/download/bayes2003/emails-for-spam-or-ham-classification-trec-2007)
- Two pre-trained models are used in this project: GPT2 and BERT. The GPT2 model is from the `transformers` library and the BERT model is from the `transformers` library as well.
